# extractors/web

Extractor implementations for web and ebook document formats (HTML, XHTML, EPUB).

---

## Files and Modules

| File | Purpose | Key Classes / Functions |
|---|---|---|
| html.py | Selectolax Lexbor HTML/XHTML DOM parser with heading hierarchy extraction. | HTMLExtractor |
| epub.py | Ebooklib EPUB chapter parser with HTML sub-extraction routing. | EPUBExtractor |
